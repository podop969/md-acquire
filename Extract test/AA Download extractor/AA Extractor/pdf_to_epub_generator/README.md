# PDF → EPUB generator

`book_pdf_to_epub.py` (and `book_pdf_to_epub_testing.py`) read **`input_book.pdf`**
from this folder.

The `input_book.pdf` shipped here is a **public-domain sample**: *Pride and
Prejudice* by Jane Austen (Project Gutenberg), so the scripts run out of the box.

## Use your own book

Drop any PDF into this folder and name it `input_book.pdf` (replacing the
sample), then run:

    python book_pdf_to_epub.py

Only use PDFs you have the right to convert. Copyrighted books are
deliberately not included in this repository.
